# Security Policy

## Supported Versions

Only the latest version of the app is actively maintained.

| Version | Supported |
| ------- | --------- |
| 0.5.x-alpha | :white_check_mark: |
| < 0.5.0 | :x: |

## Reporting an Issue

This application runs completely locally on your device—no external servers store or process your credentials or personal data. 

If you find any security bugs, unexpected behavior, or general issues:
* **GitHub Issues:** Open a new issue directly in the **Issues** tab of this repository.
